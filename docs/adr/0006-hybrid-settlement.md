# Гибридное сведение: жадный алгоритм плюс точный поиск до 12 участников

Переводы считает жадный алгоритм (максимальный должник → максимальный кредитор),
гарантирующий не более n−1 переводов; при числе участников ≤ 12 дополнительно запускается
точный bitset-поиск минимального числа переводов, и берётся лучший из двух результатов.
Точный минимум в общем случае NP-труден, поэтому порог 12 — компромисс скорости и пользы.

## Considered Options

- Только жадный: проще, но на компаниях с нулевыми подмножествами даёт лишние переводы.
- Только точный: не масштабируется за ~12–15 участников.

# Организатор — единственный редактор поездки

Поездку редактирует только создавший её организатор; все остальные открывают ссылку
в режиме зрителя (только чтение). Единственный источник правды у стейта убирает из v1
конфликты редактирования, разрешение слияний (CRDT/last-write-wins) и серверную
синхронизацию целиком. Коллаборативное редактирование — возможная v2 поверх того же
сериализуемого стейта (см. ADR 0007).

## Considered Options

- Коллаборативно с самого начала: потребовал бы бэкенда, анонимной идентификации
  устройств и разрешения конфликтов — объём работы ×3.

# Чистое ядро без зависимостей от фреймворка

Вся доменная логика — схема стейта, гроссбух балансов, сведение, кодек ссылки,
калькулятор-парсер — живёт в чистом TypeScript-модуле без импортов Vue/DOM. Vue-оболочка
только рендерит и мутирует стейт через композаблы. Единственный внешний шов — интерфейс
ядра, он же поверхность тестирования: тесты седения не знают о существовании Vue.

## Consequences

- Ядро переносится без изменений, если появится второй клиент (например, нативный).
- Глубина ядра держится малым числом экспортируемых операций (см. docs/ARCHITECTURE.md).

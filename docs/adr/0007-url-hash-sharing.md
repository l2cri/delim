# Шеринг всем стейтом в URL-хэше, без бэкенда

Ссылка вида #/t=… несёт весь стейт поездки, сжатый lz-string; в v1 нет ни сервера, ни
регистрации, ни Supabase. Схема стейта с самого начала проектируется сериализуемой,
компактной и версионируемой — задел на серверный шеринг короткими ссылками в v2 без
миграции модели данных.

## Consequences

- Длина ссылки ограничена объёмом поездки; при превышении практического порога
  мессенджеров UI предупреждает, но не блокирует.
- Импорт строгий: валидация схемы, версия и лимиты, all-or-nothing (см. SPEC.md).

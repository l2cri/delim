# localStorage вместо IndexedDB

Хранение — localStorage с дебаунс-автосохранением, а не IndexedDB из исходного питча:
одна активная поездка и один архив — это десятки килобайт JSON, а синхронный localStorage
радикально упрощает код (никаких асинхронных обёрток и миграций хранилища). Осознанное
отступление от питча; пересмотреть при появлении списков поездок или вложенных медиа.

# Стейт на композаблах, без Pinia

Единственный мутируемый стейт — сериализуемый объект поездки; вместо Pinia — композабл
над ним и localStorage. Для одной сущности без кросс-компонентных эффектов магазин
состояний — лишний слой с шаблонным кодом. Не «исправлять» добавлением Pinia, пока
модель данных не изменится (например, коллаборативность в v2).

# Одна активная поездка и архив глубиной в одну

В приложении живёт ровно одна активная поездка; завершённая остаётся в архиве только
для чтения и затирается при старте следующей. Отказ от списка поездок упрощает навигацию,
модель хранения и URL-схему; архив глубиной 1 сохраняет доступ к последним раскладам
после завершения выходных. Если появятся списки поездок — пересмотреть и хранилище (ADR 0008).

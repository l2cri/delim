# Выплата — единственный механизм закрытия долга

Долги закрываются только регистрацией выплаты «кто→кому сколько», включая частичные;
отдельного действия «закрыть перевод» тапом не существует. Предложенные переводы —
производная величина, пересчитываемая на лету после каждого изменения, поэтому сущность
«закрытый перевод» не нужна: состояние «кто с кем рассчитался» всегда выводится из
расходов и выплат, а не хранится.

# Живые ручные курсы в настройках поездки

Курс каждой валюты задаётся вручную в настройках и применяется ко всей истории задним
числом; расход хранит только сумму и валюту, без снимка курса. Приложение не ходит к API
курсов вовсе — ноль сетевых зависимостей (см. ADR 0007). Побочный эффект: правка курса
меняет балансы уже введённых расходов — это осознанное поведение, и UI обязан показывать
пересчёт явно.

## Considered Options

- Снимок курса в каждом расходе: устойчивее к правкам, но расходится с ручными курсами
  и усложняет модель.
- Автоподстановка из API: отвергнута — ломает offline-first и требует сети.

# Таск-менеджер «Делим»

Локальная доска тикетов: один файл на тикет, нумерация в порядке зависимостей
(блокаторы раньше заблокированных). Внешний трекер не настроен — если появится
(GitHub Issues и т.п.), тикеты переносятся туда с сохранением blocking edges.

## Как работать

- Назначение по агентам команды (algo-core / app-state / ui-craft / qa-acceptance) —
  в [docs/AGENTS.md](../docs/AGENTS.md), таблица «Владение тикетами».
- **Фронт работ** = тикеты, у которых все тикеты из «Заблокировано» закрыты.
  Первый тикет — [01](01-каркас-и-деплой.md), он не заблокирован ничем.
- Начинаете тикет — меняйте `Status: ready-for-agent` на `Status: in-progress`.
- Закончили — на `Status: done` и отметьте галочки критериев приёмки.
- **Done — ещё не мерж**: сначала ревью-сессия code-review в новом окне и правка
  P1/P2 (см. [docs/WORKFLOW.md](../docs/WORKFLOW.md)); мерж в master — только из
  штаба, `--no-ff`, без PR.
- Каждый тикет — вертикальный срез: проходит через ядро и UI и демонстрируется сам
  по себе. Никаких «слоёных» тикетов «сделать все компоненты».
- Термины — из [GLOSSARY](../GLOSSARY.md), решения — из [SPEC](../docs/SPEC.md)
  и [ADR](../docs/adr/). Тикет им противоречить не должен; если нашли противоречие —
  правьте документ, потом тикет.

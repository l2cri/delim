# 06: Жадное сведение

**What to build:** Операция ядра «сведение» с жадным алгоритмом: балансы → список
переводов «кто→кому сколько» (максимальный должник гасится максимальным кредитором).
Контракт: не более n−1 переводов, точные минорные суммы, детерминированность, нулевые
балансы не участвуют (ADR 0006, 0010). Это первый слой алгоритмического обещания приложения.

**Blocked by:** 05 (балансы как вход седения)

**Status:** ready-for-agent

- [ ] Классический пример из питча сводится к ожидаемым двум переводам
- [ ] Края: 0 и 1 участник (пустой результат), все в нуле, несвязные группы гасятся внутри себя без лишних переводов между группами
- [ ] Копеечные остатки: ни один перевод не нулевой и не отрицательный
- [ ] Сумма переводов погашает все балансы точно; результат стабилен при повторных вызовах
- [ ] Тесты проверяют контракт (число переводов, погашение), а не порядок обхода

# 16: Завершение поездки, удаление и архив

**What to build:** Организатор завершает поездку (с подтверждением и финальной
квитанцией/ссылкой под рукой) — она уходит в архив глубиной 1, доступный только для
чтения по `#/archive`; старт новой поездки заменяет архив (с явным предупреждением)
(ADR 0002). Это замыкает жизненный цикл единственной активной поездки.

Плюс «аварийный выход»: удаление активной поездки целиком, минуя архив. Закрывает капкан
ошибочно созданной поездки (пока тикеты 10/16 не построены, после создания вернуться к
экрану создания невозможно): если ошиблись в названии или базовой валюте — поездку можно
снести и создать заново. Пустая поездка при «Завершить» предлагает удаление вместо
архивации — мусорный архив глубиной 1 не создаём.

**Blocked by:** 12 (выплаты — цикл расчётов завершён, есть что архивировать)

**Status:** ready-for-agent

- [ ] «Завершить» переводит поездку в архив; `#/` снова предлагает создать новую
- [ ] «Удалить поездку» (danger zone) с явным подтверждением: активная поездка удаляется
      целиком, минуя архив (ключ активной поездки в хранилище чистится, архивный не трогается),
      `#/` возвращает к экрану создания
- [ ] Удаление доступно и когда в поездке уже есть расходы/выплаты — подтверждение
      показывает, что будет потеряно (счётчики расходов/выплат/участников)
- [ ] «Завершить» у поездки без расходов и выплат предлагает удаление вместо архивации
- [ ] Архивная поездка открывается только для чтения с видимой пометкой
- [ ] Старт новой поездки при занятом архиве предупреждает о замене и требует подтверждения
- [ ] После перезагрузки страницы статусы активной/архивной сохраняются
- [ ] Ссылка-приглашение на архивную поездку открывается зрителем корректно

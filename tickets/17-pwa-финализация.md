# 17: PWA-финализация, тосты и приёмочный проход

**What to build:** Финальный проход перед релизом v1: полный сценарий офлайн (создание
поездки, расходы, курсы, выплаты, сведение, квитанция — всё без сети после первого
открытия), авто-тема тёмная/светлая по системе на всех экранах, лимиты мягко подсвечены
в UI до попытки превышения, иконки/манифест/мета на месте, деплой на GitHub Pages зелёный.
Чек-лист приёмки прогоняется по [SPEC.md](../docs/SPEC.md) целиком.

**Тосты вместо нижней строки.** Сейчас все сообщения-отказы и подтверждения на экране
поездки (участник занят, лимиты, валюта в использовании, результат копирования ссылки)
рендерятся абзацем в самом низу разметки — на телефоне это за пределами видимости,
далеко от места действия. Заменить на тосты: фиксированная позиция в зоне видимости,
появление/исчезновение с анимацией, автоскрытие (~3–4 с), закрытие тапом, `aria-live`
для доступности; тон error/warn/info сохраняется. Нижний абзац-notice убрать; successes
кнопок, у которых уже есть локальная обратная связь (квитанция), не дублировать тостом.

**Blocked by:** 16 (жизненный цикл завершён — финализировать есть что)

**Status:** ready-for-agent

- [ ] Полный путь пользователя офлайн работает после первого открытия приложения
- [ ] Тема выбирается системной настройкой на каждом экране; «белых пятен» нет
- [ ] Все лимиты (участники, расходы, выплаты, валюты, длина ссылки) видны заранее, а не по ошибке
- [ ] Отказ удаления занятого участника виден сразу возле места действия: тост, заметный
      без скролла, не перекрывает критичные контролы
- [ ] Копирование ссылки даёт мгновенную видимую обратную связь тостом («скопировано»
      или ошибка), включая длинную ссылку с предупреждением; то же — для любых других
      буферных/фоновых действий без локальной обратной связи
- [ ] Тост автоскрывается, закрывается тапом, работает в тёмной/светлой теме и не ломает
      раскладку экрана (включая safe-area на мобильных)
- [ ] Манифест, иконки, экраны ошибок и пустые состояния оформлены
- [ ] Приёмочный прогон по user stories спеки не оставляет неработающих историй v1

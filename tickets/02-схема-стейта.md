# 02: Схема стейта поездки

**What to build:** Чистый TypeScript-модуль ядра без зависимостей от Vue (ADR 0003):
zod-схема сериализуемого стейта поездки — название, базовая валюта, валюты с курсами,
участники, расходы, выплаты, статус, версия схемы. Сборка валидного стейта новой поездки;
разбор и валидация чужого стейта с типизированной причиной отказа (повреждена / другая
версия / превышен лимит). Лимиты: 20 участников, 300 расходов, 200 выплат, 10 валют;
референциальная целостность (участники и валюты расхода/выплаты существуют).

**Blocked by:** 01 (каркас — там Vitest и структура проекта)

**Status:** done

- [x] Можно собрать стейт новой поездки и сериализовать его в JSON без потерь (roundtrip)
- [x] Валидный стейт проходит; каждый вид невалидного (битый JSON, чужая версия, превышен каждый лимит, висячие ссылки на участников/валюты) отклоняется со своей причиной
- [x] Версия схемы — явное поле; несовпадение даёт отдельную причину отказа
- [x] Китаю (Vue) схема доступна через экспортируемые типы, zod наружу не течёт
- [x] Тесты покрывают каждую причину отказа и границы всех лимитов

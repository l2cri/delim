# 01: Каркас приложения и деплой

**What to build:** Приложение открывается локально и в интернете по пушу в main.
Пустой каркас: Vite + Vue 3 + TypeScript + Tailwind (без UI-кита), Vitest в CI,
vite-plugin-pwa с precache, хэш-маршрут `#/` рендерит заглушку экрана «создать поездку».
Это трассер: тонкий, но полный путь от коммита до работающего офлайн PWA.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `npm run dev` поднимает приложение, `npm run build` собирает без ошибок типов
- [ ] Пуш в main деплоит на GitHub Pages; приложение открывается по URL проекта
- [ ] Vitest запускается в CI и один дымовой тест проходит
- [ ] Манифест и сервис-воркер подключены: после первого открытия приложение открывается без сети
- [ ] `#/` показывает заглушку экрана создания поездки; экран не пустой и на телефоне

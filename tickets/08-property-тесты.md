# 08: Property-тесты седения и денег

**What to build:** Третий слой тестов ядра (fast-check): генеративные проверки инвариантов
на случайных поездках и балансах. Списание нуля не происходит: сумма балансов ноль;
конвертация сохраняет сумму каждого расхода; жадный ≤ n−1; сведение не хуже жадного;
кодек roundtrip; парсер согласуется с эталонным вычислением. Тесты ловят то, чего не
придумать списком краёв.

**Blocked by:** 06, 07 (оба алгоритма готовы), 02 (кодек схемы ещё нет — кодек-тесты
допустимо временно пометить skip до тикета 15)

**Status:** done

- [x] Сведение на ≤ 12 участниках не хуже жадного по числу переводов
- [x] Сгенерированные расходы с курсами: сумма долей равна конвертированному расходу (наибольшие остатки)

# 05: Гроссбух — балансы из расходов и выплат

**What to build:** Операция ядра «балансы»: стейт поездки → баланс каждого участника
в целых минорных единицах базовой валюты. Внутри: сплиты (поровну/точно/долями) в валюте
расхода, конвертация по живым ручным курсам из настроек задним числом (ADR 0005),
распределение остатков конвертации методом наибольших остатков (ADR 0004), вычитание
выплат. Деньги не возникают и не исчезают: сумма балансов ровно ноль.

**Blocked by:** 02 (схема стейта)

**Status:** in-progress

- [ ] Расход в базовой валюте, поровну на 4: у каждого ровно четверть, сумма балансов ноль
- [ ] Расход в чужой валюте с курсом-дробью конвертируется точно; при нецелености деления остатки распределены наибольшими остатками и сумма долей равна конвертированному расходу
- [ ] Точные суммы и доли дают корректные дебеты; выплата уменьшает баланс плательщика и увеличивает получателя
- [ ] Правка курса меняет балансы уже введённых расходов (живой курс)
- [ ] Края: пустая поездка, один участник, расход без участников не проходит схему, нулевые суммы
- [ ] Все проверки — через публичную операцию ядра, без заглядывания в промежуточные структуры

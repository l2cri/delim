# 10: Валюты и курсы в настройках

**What to build:** Экран настроек поездки: список валют с курсами к базовой (пресет
популярных + ручное добавление, лимит 10), правка курса применяется ко всей поездке
задним числом — списки расходов, балансы и переводы пересчитываются мгновенно и это видно
(ADR 0005). Валюту в использовании удалить нельзя — только с понятным отказом.

**Blocked by:** 09 (расходы, чтобы пересчёт был виден на реальных данных)

**Status:** done

- [x] Курс вводится десятичной дробью; курс базовой валюты не задаётся
- [x] Правка курса сразу меняет эквиваленты в списке расходов и балансы
- [x] Удаление неиспользуемой валюты работает; используемой — отказ с объяснением
- [x] 11-я валюта не добавляется
- [x] Поездка в одной валюте вообще не требует заходить в настройки — всё работает с одной базовой

## Заметки тикет-сессии

- Интерфейс ядра расширен решением оркестратора (прецедент splitAmounts/convertToBase
  из 09): `parseRate` (src/core/rates.ts) — входная сторона к convertToBase, разбор
  десятичной дроби в несократимый Rational на bigint; оболочка по-прежнему денег
  не считает (ARCHITECTURE).
- Мутации валют в useTrip: addCurrency / updateCurrencyRate / removeCurrency с
  типизированными отказами (empty-code, duplicate, limit, bad-rate, not-found,
  base-currency, in-use со счётчиками). Инварианты схемы — курс базовой 1/1
  неприкосновенен, валюту в использовании не удаляем — защищены на уровне мутаций.
- Экран настроек — карта «Валюты и курсы» в TripScreen: модель навигции спеки
  (`#/`, `#/archive`, `#/t=…`) отдельного роута настроек не предусматривает.
  Пресет популярных валют вынесен в общий src/app/ui/currencies.ts (создание
  поездки и настройки читают один список).
- Пересчёт задним числом: эквиваленты в списке расходов меняются мгновенно
  (реактивные пропсы + живые курсы из стейта), балансы — стейт-тестом
  computeBalances до/после правки курса; экран балансов появится в тикете 11,
  механизм для него уже работает.
- Субагенты среды поднимаются по одному (лимит параллельности, как в 09):
  зону core выполнил general-purpose-агент с чартером algo-core; state и ui —
  тикет-сессия, с полным прогоном (vitest 282 + vue-tsc + build) после каждой зоны.

# 13: Граф долгов (SVG)

**What to build:** Визуализация седения: участники по окружности, отсортированные по
балансу, переводы — дуги с суммами; цвета и эмодзи участников из тикета 03. Чистый SVG
без d3-force, анимации на Vue-переходах: появление/исчезновение дуг при пересчёте,
«затухание» погашенного долга. Граф читается и на телефоне.

**Blocked by:** 11 (списание и переводы — данные графа)

**Status:** in-progress

- [ ] Все участники на окружности с именами и эмодзи; должники и кредиторы визуально различимы
- [ ] Дуги подписаны суммами; направление перевода читается без инструкции
- [ ] Изменение седения плавно анимирует появление/исчезновение дуг
- [ ] При 2 и 20 участниках граф остаётся читаемым; при нулевых балансах — пустой граф с понятным состоянием
- [ ] Ноль зависимостей для отрисовки (только SVG + встроенные переходы Vue)

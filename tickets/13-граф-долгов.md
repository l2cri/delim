# 13: Граф долгов (SVG)

**What to build:** Визуализация седения: участники по окружности, отсортированные по
балансу, переводы — дуги с суммами; цвета и эмодзи участников из тикета 03. Чистый SVG
без d3-force, анимации на Vue-переходах: появление/исчезновение дуг при пересчёте,
«затухание» погашенного долга. Граф читается и на телефоне.

## Заметки сессии

Карточка `DebtGraphCard.vue` сразу после «Сведения» на экране поездки. Денежная логика —
только ядро (`computeBalances` → `settle`); всё остальное в компоненте — геометрия показа.
Сортировка: баланс по убыванию с 12 часов по часовой (тай-брейк — порядок участников,
как в остальном UI), нулевые — между кредиторами и должниками. Дуга — quadratic bezier
к центру, стрелка-треугольник по касательной вручную (без marker), подпись `formatMinor`
у середины с ореолом; цвет дуги — цвет кредитора. Нода: круг цвета участника + эмодзи,
имя снаружи (полюсные — по центру, боковые — anchor по стороне, длинные с «…»), баланс
тонами SettlementCard (emerald/red/zinc). Размеры адаптивны 4→20 участникам.

Покрытие критериев: дымовые `tests/smoke/debt-graph.test.ts` — ноды/тона/сортировка по
координатам, дуги с aria-label «X переводит Y-е сумма RUB» и стрелками, EUR-расход в RUB,
лимит 20 (число дуг = сечению ядра), пустые состояния, живой пересчёт расходом.
GUI-прогон оркестратора (браузер, 390px, тёмная тема системы): 2 (длинное имя «Борислав»
читается полностью), 4 и 20 участников (подписи не слипаются, стрелки читаемы; центр при
19 дугах плотный — осознанный компромисс v1), выплата 333,33 из #12 — дуга Бори гаснет
leave-переходом 0,6 с («затухание»), остаётся дуга Вики, список седения согласован.

Ветка подтянула master перед закрытием (#12: общий конфликт — одна строка заглушки
«Что дальше», разрешён в «Дальше — квитанция»); дымовые переведены на общие
`tests/helpers/smoke.ts` из #12. Тесты 337 зелёные, `vue-tsc`/build проходят.

Отложенное (кандидаты в ревью/будущие тикеты, не блокируют):

- `ParticipantAvatar` из P3 ревью #11: SVG-нода графа — не HTML-спан, компонент-обёртка
  её не покрывает; рефакторинг 6 мест — конфликтная поверхность с параллельными
  ветками. Остался кандидатом на спокойный проход (например, в 14).
- Светлая тема проверена на уровне классов (симметрия dark:/light: как во всём UI);
  GUI-прогон шёл в тёмной теме системы.
- `dative()` — эвристика дательного падежа для aria-label: классы окончаний только
  кириллические, латиница и незнакомые окончания проходят без искажения (как есть).

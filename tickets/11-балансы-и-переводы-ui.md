# 11: Балансы и минимальные переводы на экране

**What to build:** Экран седения поездки: балансы участников («должен X ₽» / «должны ему
Y ₽», сортировка по величине) и минимальный список переводов «А → Б сумма» из операции
седения ядра. Всё производное — вычисляемые значения поверх ядра, оболочка денег не считает.

**Blocked by:** 06 (сечение ядра), 09 (расходы — данные для балансов)

**Status:** ready-for-agent

- [ ] Балансы каждого участника видны с знаком и сортировкой
- [ ] Список переводов соответствует результату седения; пуст, когда все в нуле
- [ ] При изменении расходов/курсов (тикет 09/10) экран обновляется мгновенно
- [ ] Суммы отформатированы в базовой валюте с минорными единицами

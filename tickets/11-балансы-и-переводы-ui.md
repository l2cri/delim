# 11: Балансы и минимальные переводы на экране

**What to build:** Экран седения поездки: балансы участников («должен X ₽» / «должны ему
Y ₽», сортировка по величине) и минимальный список переводов «А → Б сумма» из операции
седения ядра. Всё производное — вычисляемые значения поверх ядра, оболочка денег не считает.

**Blocked by:** 06 (сечение ядра), 09 (расходы — данные для балансов)

**Status:** done

- [x] Балансы каждого участника видны с знаком и сортировкой
- [x] Список переводов соответствует результату седения; пуст, когда все в нуле
- [x] При изменении расходов/курсов (тикет 09/10) экран обновляется мгновенно
- [x] Суммы отформатированы в базовой валюте с минорными единицами

Критерий «экран обновляется мгновенно» покрыт дымовыми на изменение расхода
и на правку курса валют (экран курса приехал из тикета 10, подтянут в ветку
перед мержем).

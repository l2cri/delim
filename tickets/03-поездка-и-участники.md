# 03: Создание поездки и участники

**What to build:** Организатор создаёт поездку (название + базовая валюта из пресета
популярных с возможностью ручного добавления) и управляет участниками: добавление по
имени, автоподбор цвета и эмодзи с перегенерацией из палитры, свободное переименование,
удаление только тех, кто не фигурирует в расходах и выплатах (с понятным отказом),
лимит 20. Поездка автоматически сохраняется в localStorage с дебаунсом ~500 мс и
загружается при старте приложения (ADR 0008, 0009).

# 04: Калькулятор-парсер выражений

**What to build:** Операция ядра «калькулятор»: строка выражения с `+ - * / ( )`,
запятая равнозначна точке, унарный минус поддержан — результат в минорных единицах,
некорректное выражение («некорректно», не исключение). В UI — инпут суммы, который
живым предпросмотром показывает результат («1500/4+200 → 575,00») и тихо подсвечивает
некорректное. Никакого кастомного keypad.

**Blocked by:** 01 (каркас — там Vitest)

**Status:** done

- [x] Парсер ядра: корректные выражения вычисляют точно (целые минорные единицы, деление — рациональное с округлением до минорной на выходе)
- [x] Пустая строка, мусор, незакрытая скобка, деление на ноль — «некорректно», не исключение
- [x] «1,5» и «1.5» равнозначны; унарный минус и вложенные скобки работают
- [x] Инпут-компонент показывает живой предпросмотр результата и подсветку некорректного
- [x] Тесты парсера включают перечисленные края

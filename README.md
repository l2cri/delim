# Делим (delim)

Offline-first сплиттер общих расходов для поездок и тусовок: организатор раскидывает чеки
по компании в разных валютах, приложение выдаёт **минимальный список переводов** для
погашения всех долгов. Без регистрации, без сервера, без сети — весь шеринг через ссылку,
внутри которой лежит сжатый стейт поездки.

> Рабочее название проекта — «Делим». Название и домен выбираются до деплоя.

## Что это

- Организатор создаёт поездку, добавляет участников и расходы; участники открывают ссылку
  как зрители (только чтение).
- Расходы делятся поровну, точными суммами или долями; суммы вводятся калькулятором-выражениями.
- Валюты с ручными курсами в настройках; правка курса пересчитывает поездку задним числом.
- Долги закрываются выплатами «кто→кому сколько»; сведение пересчитывается на лету.
- Данные — localStorage; шеринг — URL-хэш (lz-string). Ноль сетевых запросов.

## Стек

Vite + Vue 3 + TypeScript · Tailwind (без UI-кита) · vite-plugin-pwa · Vitest + fast-check ·
lz-string · zod · деплой GitHub Pages. Стейт — на композаблах, без Pinia. Ядро домена —
чистый TypeScript без зависимостей от Vue.

## Разработка

```bash
npm install
npm run dev        # дев-сервер в корне
npm test           # vitest run
npm run build      # vue-tsc --noEmit + vite build
npm run preview    # раздача dist (с той же базой, что у сборки)
npm run icons      # регенерация PWA-иконок (public/)
```

База деплоя (`/delim/`) выводится из `GITHUB_REPOSITORY`: в GitHub Actions она есть
всегда, локальные сборки и дев-сервер живут в корне.
